# App Store Connect listing

Field limits are hard caps. Counts below were measured, not estimated.

| Field | Count | Value |
|---|---|---|
| Name | 29/30 | `Teardown: Competitor Research` |
| Subtitle | 30/30 | `Screenshots, saved and tagged.` |
| Keywords | 91/100 | `ui,ux,design,inspiration,swipe file,moodboard,wireframe,figma,inspo,reference,audit,pricing` |

Apple indexes **name + subtitle + keywords as one pool**, so a word already in
the name or subtitle is wasted in keywords. The list above has zero overlap
with the other two fields.

`screen capture` is deliberately not in the name: it makes the app sound like a
screenshot utility rather than a reference library, and it is a generic term
this app will not rank on. It still indexes through keywords.

Softer alternative if `Competitor Research` reads too PM-flavoured for the
designer half of the audience — same coverage, different emphasis:

- Name `Teardown: Design Reference` (26)
- Subtitle `Competitor research, tagged.` (28)

## Promotional text (150/170)

> A teardown library for designers, PMs and solo founders. Save a screenshot,
> tag where it came from and what you are building. Find it again by either.

## Description opening

> Teardown isn't a bookmark manager. It's a reference library for people who
> study other products as part of the job — designers, PMs and solo founders.

Positions against a category in the first line, the same move mymind makes with
"mymind isn't another productivity app".
