# Teardown

> <span class="hl">Every capture is a screenshot plus two pieces of human context.</span>
> Which product it came from, and which idea it might help. That relationship is
> the product; the screenshot is evidence and the tags make it retrievable.

## What it does

Screenshot anything worth keeping, share it to Teardown, and tag it twice —
**FROM** the product you found it in, **FOR** the idea it might help. Later you
can ask what you have collected for an idea, whoever you found it from.

Share a web page instead of an image and Teardown keeps the page's markup
alongside the screenshot, so a reference can be handed to Figma or to a coding
agent rather than only looked at.

## Where your references live

On your device, and nowhere else. There is no account and no server. See the
[privacy policy]({{ '/privacy.html' | relative_url }}).
